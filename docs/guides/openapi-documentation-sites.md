# 发布 OpenAPI 文档站

服务中的 OpenAPI 规范可以将已保存修订发布为独立阅读站。工作区 owner/admin
打开规范根节点，进入“分享文档”。接口目录和模型目录由这份规范生成。

## 发布流程

1. 保存规范，选择“分享文档 → 新建分享”。
2. 选择已保存修订，填写文档标题、说明，设置浅色/深色主题，决定是否显示
   OpenAPI 下载入口和在线调试工作台。
3. 可选：在“公开运行环境”中复制服务环境或手动添加，核对环境名称、Base URL 和普通变量。
   敏感、停用和无值变量不会复制；可编辑和移除复制的字段。域名必须展开为完整 HTTP(S)
   地址，不能含账号密码、查询参数或片段，环境名与变量名不可重复。
4. 在预览中检查目录、鉴权、参数、请求、响应和引用字段。预览及其下拉菜单、弹窗
   使用所选阅读主题，不改变工作区主题；取消不会创建站点。
5. 选择“发布分享链接”，复制或打开生成的随机子域名。

文档固定在选中的修订，不包含编辑草稿，也不会随源规范自动变化。
后续内容更新需保存并发布新的修订。每个修订只能有一个有效链接；撤销后可以重新发布，
生成新的链接。发布、撤销不会修改规范内容、ETag 或修订历史。

## 读者能力

- 无需登录，按 Tag 浏览接口；每个 Tag 有展示全部接口的概览页，数据模型有独立目录。
  搜索覆盖方法、路径、摘要、标签、参数与引用模型字段，支持多个关键词共同匹配。
  顶部“搜索文档”或 `Ctrl+K`（macOS 为 `⌘K`）可定位搜索框，窄屏会同时展开目录。
- 概览展示 API 版本、说明、维护者、许可证及外部文档；只有规范中声明的信息才会展示。
- 接口页展示鉴权方案、参数位置、字段约束、默认值、请求体、响应状态、响应头和
  具体引用字段。可切换媒体类型和具名示例，复制页面 Markdown、请求代码或示例。
- 请求代码跟随所选正文示例；响应结构与右侧示例使用相同的状态和媒体类型。
- 请求代码以统一的“语言 + 客户端”选择器提供 20 种组合，包括 Shell 的 cURL、
  HTTPie、wget、PowerShell，JavaScript 的 Fetch、Axios、jQuery、XHR、Node.js、
  Request、Unirest，Java 的 HttpClient、Unirest、OkHttp，以及 Python、Go、PHP、
  Ruby、C#。代码可复制，开放下载时也可保存为对应扩展名的文件。
- 可预览或复制当前接口、模型的 Markdown，复制页面链接和 OpenAPI 定义。
  开放下载时，可导出整份文档或当前接口的 OpenAPI JSON/YAML、Markdown、离线 HTML
  和 LLMs.txt 索引。当前接口的定义导出保留相关模型及鉴权引用。
- 模型和请求/响应结构支持在浏览器本地生成 TypeScript、JavaScript、Python、Java、
  Go、C#、Rust、Kotlin、Swift、Dart、PHP、Ruby、C++ 代码；可配置顶层类型名称，
  TypeScript 还提供类型与运行时校验选项。结果可复制，开放下载时也可保存为文件。
- 启用在线调试时，读者进入独立“调试工作台”Tab，选择公开环境或填写完整 HTTP(S)
  地址和自己的凭据。环境普通变量支持 `{{变量名}}` 和 `<<变量名>>`，可在当前页面临时
  修改或重置；不会改写发布快照。数值参数也可输入变量占位符。缺少地址时发送按钮
  给出字段提示并定位地址输入框。浏览器直接发送请求，目标 API 需允许 CORS；Cookie 等受浏览器限制。
- 页面链接携带所选 Tag、接口或模型的片段，刷新、返回和前进可恢复阅读位置。
  搜索词在当前阅读会话的目录切换中保留；切换页面后键盘焦点进入内容标题。

发布默认移除源规范中的服务器地址和已有环境扩展，不自动发布工作区环境。只有发布者
明确添加的公开运行环境进入快照。OpenAPI JSON/YAML 的完整文档和单接口导出均保留
`servers` 和 `x-specx-public-environments`；重新导入 SpecX 后可直接选择这些环境调试，
其它兼容工具可读取标准 `servers`。普通变量以明文公开；密钥不复制，平台还会拒绝包含
已知工作区 Secret 值的内容或公开环境配置。发布者仍应审核普通变量、说明和示例。
生成代码中的示例地址和鉴权占位符需要按目标系统替换。关闭下载入口不会阻止读者复制已公开内容。

## 域名和部署

发布链接格式为 `https://<32位随机ID>.<应用域名>/`。部署人员需要将应用域名及其
通配子域名指向同一 Web Host，配置相应 TLS 证书，并转发页面、静态资源及
`/api/specx/public/openapi/`。工作区写操作继续使用原应用域名。
具体部署要求见 [Docker 部署说明](../../deploy/dockerhub/README.md)。

本机安装生成 `<随机ID>.localhost:<端口>`，只能在运行 SpecX 的机器访问。
另外支持 `/docs/openapi/<随机ID>` 路径入口。SpecX 创建发布 ID，不申请公网域名、
配置 DNS 或签发 TLS 证书；桌面本机实例也需要 Web Host 才能对外提供文档站。

撤销会令后续公开读取返回 404，页面显示链接失效提示；已下载的副本无法收回。
密码、有效期、接口范围筛选和独立自定义域名配置尚未提供。
